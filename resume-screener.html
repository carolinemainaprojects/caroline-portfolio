PROJECT 01

AI Resume Screener

An AI-powered recruitment assistant that analyzes resumes against job descriptions and generates structured candidate insights.

Live Demo → View GitHub →

The Problem

Reviewing large numbers of resumes against job descriptions can be time-consuming and repetitive. Recruiters need a faster way to identify relevant candidates and understand how closely their experience matches a role.

The Solution

I built an AI-powered resume screening application that allows a user to upload a PDF resume and provide a job description. The application extracts the resume text and sends the relevant information to an AI model for structured analysis.

How It Works

01 — Upload

User uploads a resume in PDF format.

02 — Extract

The application extracts text from the PDF.

03 — Analyze

Gemini AI evaluates the resume against the job description.

04 — Results

The application presents scores, strengths, weaknesses, and job-match insights.

Key Features

Resume PDF upload
Job description analysis
AI-generated candidate evaluation
Resume score
Job match score
Strengths and weaknesses

PROJECT 02

AI Meeting Summarizer

An AI-powered application that transforms meeting notes and transcripts into structured summaries, decisions, and actionable tasks.

View GitHub →

The Problem

Meetings often generate large amounts of information that can be difficult to organize and revisit. Manually creating summaries, identifying decisions, and tracking action items takes time and can lead to important details being missed.

The Solution

I built an AI-powered meeting summarization application that processes meeting notes or transcripts and converts them into structured, useful information.

The application uses Gemini AI to identify the most important information from a meeting and organize it into a clear summary, decisions, and action items.

How It Works

01 — Input

User provides meeting notes or a transcript.

02 — AI Processing

Gemini AI analyzes the meeting information.

03 — Structure

The AI organizes the information into key sections.

04 — Output

The user receives a summary, decisions, and actionable tasks.

Key Features

AI-generated meeting summaries
Decision extraction
Action item identification
Structured output
Downloadable results
Google Sheets integration

Technology Stack

Python Gemini AI Streamlit Google Sheets API Google Cloud GitHub

01

AI Resume Screener

Problem

Initial resume screening can require recruiters to manually compare candidate information with job requirements.

Solution

Built an AI-powered recruitment application that accepts a PDF resume and job description, extracts the resume text and uses Gemini to evaluate candidate suitability.

Key Features

  • PDF resume upload and text extraction
  • Resume and job-match scoring
  • Skills, strengths and weaknesses
  • AI-generated recommendations
  • Streamlit web interface

Outcome

Created a working recruitment assistant that demonstrates document processing, LLM integration, structured AI analysis and deployment.

PDF Resume → Text Extraction → Google Gemini → AI Evaluation → Scores + Candidate Insights
